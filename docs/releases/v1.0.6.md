## Shenzhen KVM 1.0.6

### Linux computers running Weston
- **Weston desktops work.** A Linux computer whose desktop is Weston rather than X, such as a single-app kiosk, can now be shared once its Weston loads the `kvm-desk.so` module. The pointer moves across all of its screens, crosses at any outer edge as before, and is hidden there while it's on the Mac. Copy and paste work both ways: text, pictures and files.
- **Clicks land where the pointer is.** A click or scroll right after a move waits for the move to be applied on the Weston desktop, so it never lands where the pointer was a moment before.
- **Limits.** Text and pictures copied to a Weston desktop can be up to 16 MB; copied files have no such limit.
- **Choosing the desktop.** Shenzhen KVM uses Weston whenever its module answers, else X, and switches by itself when the desktop changes. To fix one, add `"desk": "weston"` or `"desk": "x11"` to `/etc/shenzhen-kvm/config.json`.

## Updating

Install the Linux side from the repository (`linux/install.sh`). On a Weston desktop, Weston must also load the `kvm-desk.so` module (in its configuration's `[core] modules=` line).

The Mac app has no changes in this version.
