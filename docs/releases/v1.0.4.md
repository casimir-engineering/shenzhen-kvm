## Shenzhen KVM 1.0.4

### Copied files
- **Removed once pasted.** Files you receive wait in Downloads › From <the other computer> until you paste them. When the program you pasted into has finished copying them, they're removed. A second paste of the same files then offers nothing; copy them again on the other computer if you need them twice.
- **The last 5 kept.** Copies you haven't pasted stay, up to the 5 most recent; older ones are removed. Only the folders Shenzhen KVM made are ever removed; anything else you put in that folder stays.
- **Not sent twice.** A file the other computer still has from an earlier copy isn't sent again, so copying the same file twice in a row arrives at once, and copying a folder again sends only what changed. Every file that is sent is checked when it arrives; a damaged one is not kept.
- **Copies no longer go missing** when the other computer is slow to answer for a moment.

### Linux
- **No more flicker.** Linking the two computers again, or editing the Linux computer's settings file, no longer makes its desktop drop Shenzhen KVM's pointer and keyboard for a moment.

## Updating

Shenzhen KVM 1.0.2 offers this update by itself within a day, or choose **Check for Updates…** in the app menu. Your link, settings and the permission to use the keyboard and mouse stay as they are.

Update the Linux side too, from the repository (`linux/install.sh`): it has the same changes.
